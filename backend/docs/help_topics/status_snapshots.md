# Satellite snapshots

id: status_snapshots
short: Verified satellite pictures: Samui, Gulf of Thailand, SE Asia haze, Pacific SST.

## What it is
Status key snapshots {items: [{id, title, date, url, worldview_url, description}], failed}. Each image was downloaded once and checked to contain data.

## How to read it
True colour: white = cloud, grey-brown veils = smoke/haze. Aerosol map: yellow to red = thick haze. SST anomaly: red = warmer than normal, blue = cooler; the dark red equatorial band is El Nino.

## Why it matters for Koh Samui
A fast visual check of storms, haze and the state of El Nino.

## Limits
Satellite pictures are from yesterday; clouds hide the ground.
