# GRACE-FO drought maps for Asia

id: status_grace_drought_asia
short: Latest weekly groundwater and soil-moisture drought maps (images).

## What it is
Status key grace_drought_asia {date, maps: [{id: gws|rtzsm|sfsm, title, url, pdf}], legend}.

## How to read it
Wetness percentile vs 1948-2012: dark red <= 2, red 2-5, orange 5-10, tan 10-20, yellow 20-30, white 30-70 normal, blues wetter.

## Why it matters for Koh Samui
Shows long-lasting El Nino drought in Thailand's groundwater and soils.

## Limits
Coarse (~300 km underlying resolution); weekly.
