# Cloud top temperature

id: layer_cloud_top_temp
short: Temperature at the top of clouds (afternoon pass).

## What it is
MODIS Aqua cloud product (about 1:30 pm pass).

## How to read it
Kelvin, 150-350 K: below 220-230 K (about -50 degC) = tall thunderstorm towers.

## Why it matters for Koh Samui
El Nino shifts deep thunderstorms from SE Asia toward the central Pacific.

## Limits
One snapshot a day; the Himawari infrared layer is the live view.
