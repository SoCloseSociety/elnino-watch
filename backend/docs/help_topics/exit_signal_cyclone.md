# Exit signal: tropical cyclone nearby

id: exit_signal_cyclone
short: The nearest tropical cyclone reported by GDACS or NASA EONET.

## What it is
Distance from home to each active cyclone's last reported position.

## How to read it
None within 800 km: ok. Any cyclone within 800 km: caution. Within 300 km, or an orange/red GDACS alert within 800 km: blocked. Feeds not received recently: unknown. A cyclone signal also marks the first 3 days of the departure windows.

## Why it matters for Koh Samui
Cyclones reach Samui rarely but hard (Harriet 1962, Gay 1989, Pabuk 2019), mostly October-January. The sea closes before the storm arrives, so the time to leave is while it is still far away.

## Limits
The last reported position is used, not the forecast track. Check the TMD for the official track.
